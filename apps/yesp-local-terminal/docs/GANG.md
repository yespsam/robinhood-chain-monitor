# Gang 平台 — 1.7.0

打开本地面板 http://127.0.0.1:8717/，在战壕筛选 Gang，或粘贴 Gang 代币 CA / 官网代币链接。与 Four.meme、Flap 共用现有币安 Agentic Wallet 登录。

## 交易

- 已接入 BSC 主网 LaunchpadV2、Soft，以及 U/S 存量曲线。合约地址和代码哈希固定核验；官网 API 只提供显示资料，不决定交易合约或授权地址。
- 输入目标代币数量后，按链上曲线反算固定投入，最低收到量受用户滑点约束。金额按资产实际小数位计算。持仓限额由合约读取，默认 1% 总量、即 1000 万枚；卖出会恢复可买额度。
- Soft 用原生 BNB；V2/U/S 用该市场的 ERC20 结算资产。WBNB 与 BNB 分开显示。WBNB 不足时先单独预览所需差额的 1:1 包装，用户确认后才能提交；完成后重新核对买入，授权和买卖仍分别确认。
- 买卖复用既有币安预演、共享交易锁、交易日志和回执核验。仅授权准确数量；非零旧授权先清零。当前钱包必须通过合约 Agent ID 检查。
- 内盘代币锁定钱包间转账，毕业后才能在同页转出。已毕业市场显示在“已开盘”，此版本尚未接入 Gang 的 PancakeSwap 外盘交易。
- 指定 CA 的单次狙击复用现有参数和授权流程；需要包装 WBNB 或代币授权时暂停，不自动执行准备交易。未在开发过程中开启任何自动交易。

## 扫描、K 线、分红

- 扫描 V2 创建事件，目录每 30 秒按已核验合约读取各版本最新 100 个代币；区分内盘、接近毕业和已毕业。不是全量历史索引。
- 官网目录为名称和头像提供补充数据，市场归属、毕业状态、结算资产和限额以链上为准。头像通过受限的媒体代理懒加载，继续保留每栏默认 20 张卡片及后台标签页暂停刷新等性能优化。
- GMGN 收录的代币可使用原有美元 K 线；未收录时使用 Gang 买卖事件生成链上 K 线，单位是该市场结算资产，不是美元。链上图只含内盘交易，外盘行情需 GMGN 收录。
- V2 内盘收取 1% 平台费，不产生持有人分红。税币毕业后有交易税，keeper 处理后才计入分红。旧 U/S 税币有不同的内盘分配规则，面板分别标明。未核验的累计分红金额显示为缺失，不显示虚构收益。

## 更新报告

Gang 官方合约和 CLI GitHub 纳入更新报告。首次读取只建立基线。后续更新先在网页报告，不从 README 自动执行命令或接受新合约。Gang 新模式主网部署与首币证明尚须人工核验和适配；报告显示待核验，不能直接授权未知新模式。此次看到的 FairMint 文档是测试网资料，未作为 BSC 主网交易模式接入。
