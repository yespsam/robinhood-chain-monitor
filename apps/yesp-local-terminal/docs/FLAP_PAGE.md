# Flap 当前代币识别 · YESP 0.3.1

修复页面：<https://flap.sh/apps/agent-bonding-curve?lang=zh>。

该应用在同一个网址内切换市场。旧版面板固定显示 Heyi.ai 和旧 Market 地址，没有读取用户选择。现在只读取官方应用当前可见详情中的地址卡片，分别显示“预测代币 CA / 代币 CA”和“Market 市场地址”；不从创建者地址、持仓列表或整页任意 0x 字符串猜测 CA。

读取后通过 BSC 官方应用 Factory、Reader 和 Portal 的公开合约核验市场登记、预测 CA、实际 token、名称与报价资产。地址正确不等于已经允许交易；尚未发射的预测 CA 也不等于已经部署的 BEP-20 代币。

支持中文、英文地址标签、创建完成后的详情卡片和开放 Shadow DOM。DOM 变化及定时扫描跟随同页切换；多个冲突地址、截断 CA、返回列表或页面结构无法识别时清空选择，不回退到 Heyi.ai。未查询网页钱包、React 私有状态、网页存储或剪贴板，不接受网页 postMessage 指定交易地址。

切换立即清除旧持仓、报价及已核验绑定，忽略旧市场延迟返回的响应。每次更新报价和提交前重新检查当前选择；浏览器和本机协议要求同时带 expectedMarket、expectedToken，本机再次与已核验配置及链上 predictedToken/token 比较，不允许把新币显示成旧币后仍交易旧市场。

本次增加动态 CA 识别和公开只读市场查询，未自动生成或放宽私有交易配置。原 Flap 买卖仍只在本机已有、经过核验的 profile 与当前选择一致时可用。不同市场将显示配置不匹配并阻止旧市场操作；Four.meme 的既有交易功能不受此限制影响。

## 更新后使用

1. 在 Chrome 的 chrome://extensions/ 页面重新加载 YESP。
2. 刷新 Flap 网页，进入具体代币详情。
3. YESP 顶部应显示当前代币名称、完整 CA、Market 地址；切换另一个代币时两者随之改变。当前底部版本为 0.3.2。
4. 若显示“交易配置不匹配”，说明新地址已经识别，但该市场不能使用旧 profile 交易；不要修改地址或确认字段来绕过核验。
