# BSC 单链交易扫描 · 2026-10-04

## 范围

按用户要求将新交易机会扫描收敛到 BSC。只限模拟盘；不签名、不广播、不真实买卖。不修改入场/退出规则、税率限制、限流、余额、实验身份及历史成交。GMGN 跟踪技能与 Web3 安全验证技能用于约束只读采集和执行边界。

独立配置：`data/trading-scan-scope.json`，内容为 `{"version":1,"chains":["bsc"]}`。启动时加载；无配置沿用原链范围，配置损坏不静默扩大扫描范围。账本中的历史 `chain/chains/session` 保留，不能拿它们当作当前扫描范围；真实范围由 API `scanScope` 返回。

- 模拟盘：一分钟/一小时榜单、内盘发现、资料补充、事件触发、旧叙事召回与新仓候选均按 BSC 限定。缓存的非 BSC 信号不能绕过范围进入新仓。
- GMGN、币安备用钱包资金流：轮询 BSC。若重启时仍有其他链模拟持仓，保留其资金流监测；既有仓位报价/K 线/退出仍独立运行。退出后至下一次重启可能保守保留该链资金流，不重新开放新仓。
- 交易配套钱包学习：新增活动、画像与历史 K 线请求按 BSC 选择；旧画像、记录及被暂停的画像请求检查点保留。固定公共参考地址的独立低频研究安排未修改。
- 主 TG 新闻、官方事件、GMGN 社交/推文发现不关停。这些新闻/研究仍可能占用部分共享额度，所以不是整套系统只剩 BSC 网络请求。
- 看板页头、行情覆盖统计、扫描速度栏改为显示真实扫描范围；公共状态投影只增加脱敏的链范围字段，未做新的公开部署。

## 结论与下一步

单链减少多链轮询与跨链候选研究的竞争，也会主动放弃其他链的新机会；不能证明策略盈利。当前仍有 GMGN 共享请求排队，接下来应对照事件到达、资料补齐、报价排队和决策时间分别测延迟，而不是进一步放宽买入条件或编造秒级速度。本次不恢复十分钟/Jev 复盘，不改百笔本地复盘设置，不处理旧 BSC 待扫积压。
