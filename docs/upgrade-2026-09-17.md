```sh

npm run health -- --json
npm run health -- --no-write
```

默认按需刷新 `data/health.json`，它不是独立持续更新的看板；`--no-write` 仅诊断。命令不调用 Telegram 或外部健康回调。

备份权限为仅当前用户读写。回滚必须先停止对应写入者并检查升级后新增状态；不可直接覆盖实时 outbox，否则可能造成重复发送或状态丢失。
