# 自动交易软件：异步订单开发阶段

此版本增加可持久化的订单协调核心，不是已经可用的实盘自动交易机器人。所有入口固定 `offline_replay`、`executable: false`；没有连接钱包、导入私钥、自动签名、发送交易、自动充值或提款功能。GMGN 模块只生成参数和解析回执，不运行命令。

## 已实现并可离线验证

- BSC 整数金额计划：固定绝对数量、1% 滑点、anti-MEV 参数，不用百分比卖出。
- 独立账本、单写进程锁、原子持久化与完整性校验。先保存资金预留，再保存提交中状态，然后才调用离线替身。
- 区分预留、提交中、等待回执、待核实和确认成交；重启只查询已知订单，不盲目重新买入。
- 候选必须包含有来源的叙事、精确合约与池子、及时安全证据。资料不全只观察。这些字段仍需独立可信采集，字段为 true 不等于现实中已验证。
- 退出按实际持仓数量；暂停新买入不会阻断退出与对账。未知回执、部分成交、费用超限、失败费用不明均保留占用，不假装资金已经退回。
- 已确认回执重复出现不重复记账；冲突回执停止新增仓位。退出待确认时不会生成第二笔退出订单。

参数仅为开发假设：100 美元虚拟本金、每笔 10 美元、最多两仓、保留 20 美元、每边 gas 上限 0.25 美元；20% 止损触发、40% 止盈触发、最长持有 30 分钟；UTC 当日已实现亏损累计 5 美元、总已实现亏损累计 10 美元停止新增仓位。止损是触发条件，不保证成交或最大亏损。盈利不抵消累计亏损计数；目前未实现包含浮亏的权益熔断。

## 演练命令

在项目目录运行：

```sh
npm run test:trade-bot
npm run bot:replay
npm run bot:replay -- --scenario timeout
npm run bot:status -- --data-dir /absolute/directory/from-replay-output
```

未指定目录时，每次演练都会创建独立临时目录，输出其路径。也可指定新的绝对路径 `--data-dir`。已有账本拒绝再次初始化或覆盖。状态查询只读，不创建新资金。演练不改原 `paper-100` 账户、监控配置或“模拟净利润 10 万美元”提醒。

`roundtrip` 使用**完全合成**的候选、报价和成交回执，演示挂单、确认、暂停买入后触发止盈、退出结算；数字由测试夹具设定，不能当作回测、实际收益或盈利能力证明。`timeout` 演示回执丢失时保留资金占用且不重复提交。

估值仅在夹具中假设 BSC USDC 为 18 位且一枚等于一美元，未接现实美元价格、脱锚检查或原生 gas 余额。没有手续费代币余额就无法执行真实交易，虚拟现金不是可花的钱包余额。

## 仍未完成的实盘前置部分

1. 可信、独立、自动化的安全证据采集与叙事验证，不能从监控热度直接授权交易。
2. 由用户自行部署控制的真实执行器、签名隔离、权限与额度管理。
3. 链上最终确认、钱包归属与余额/nonce 对账、重组处理，以及真实价格、gas 余额和路由验证。
4. 部分成交、失败 gas 和取消后的财务结算；目前只支持完全匹配意图的 ExactIn 完整回执，否则待人工核实。
5. 长期历史/前向模拟、包含浮亏的熔断、行情中断与恢复演练。

因此这次没有开启实盘，也没有保证任何收益。

## 故障恢复

崩溃留下的进程锁不会自动抢占；持久化失败会保留故障锁。初始化哨兵存在但账本缺失时禁止补发虚拟本金。不要直接删锁再重跑。先停止关联开发进程、保留整个目录、核对状态与故障原因；无法确认订单的，继续保留占用。当前提供读取和查询恢复，不提供自动清锁、自动修账或无订单号时重新提交。
