# 逐币判断台

入口：`http://127.0.0.1:4173/#caDesk`，持仓下方。

只读复用每 2 秒 `/api/strategy-state`；不新增行情请求、不修改策略、账本、费用或开关，不调用订单、签名、广播、发帖接口。无需重启后台。

按链 + 精确 CA 聚合本轮全部 evaluations 与主账户持仓，不按同名币合并、不混入独立对照账户。页面数量是本轮可见范围，不是全链覆盖。支持币名 / 完整 CA、链、状态筛选；刷新数据保留仍在筛选范围内的选择及滚动位置。

摘要展示：现在结论、路线事实、原始叙事及缺口、资金流覆盖与筹码集中度、下一触发条件、失效 / 持仓依据、成本假设、全部路线未过条件。直接来源于引擎证据和已记录规则，不是模型内心独白、概率或收益预测；缺失数值与真实零分开。持仓引用冻结入场版本与退出规则。

满足条件仍不是成交：引擎许可、行情 / 独立报价时效及账户状态共同检查。信号已成立但仍有成本或买盘缺口时，不写成仅等待报价。收盘线时效使用具体机会路线的 closedAt，不用较宽松的通用 chart.ready 代替。网络失联保留上次摘要但明确标记，不假装最新状态。

判断变化仅保留本页打开后的最近 5 次采样变化，刷新页面重置；重复轮询不增条目，候选离开本轮集合时清理，不宣称永久历史复盘。

验证：`node --test test/ca-desk.test.js test/dashboard.test.js`。
