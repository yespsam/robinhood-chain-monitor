# 事件先行叙事案例学习

这层学习把已经接入、通过来源校验的事件先入库，不等代币达到高市值或放量门槛。它与原有“起量案例学习”并行，不新增交易权限，也不自动修改策略。

## 学什么

- 动物与图片符号、Meme 文化、人物参与与认领。
- 平台 / 项目催化、Web2 / 技术文化、币股 / 底池机制。
- 账号异常 / 盗号事件（独立于正常名人背书）。

现阶段使用可检查的规则归类，不声称通用语义理解、图片识别或训练了模型。图片含义、OG / 发行者身份、认领交易、池子关系、钱包同控需要独立证据。用户提及的牛来、Marscoin 等是研究方向，不在没有原始来源和链上对应关系时预置为已确认案例。

## 时间和证据

每个事件保留原文时间、系统首次收录时间、来源及内容指纹。每个关联以链和 CA 区分；原文精确 CA、项目引用原帖、仅名称 / 标签猜测分开存储。原始关联不被后续资料覆盖；另记当前关联。

同文案转发不是新催化。同作者且有明确关联的同 CA 不同文案，只标记“后续线索待核实”，不会凭出现次数断言二次或三次发酵。跨作者传播或仅同一种动物不自动合并为同一个叙事。

普通英文词（如 This / Test）、网址路径和单词内部子串不再成为名称命中。显式 cashtag / hashtag 可以产生研究假设，不能认证 CA 或产生买入许可。

## 观察结果

按首次取得的新鲜报价建立观察基线；记录 5 分钟、1 小时、24 小时窗口。只接受同链同 CA、新鲜且在窗口内的后续价格；窗口缺失就记缺失，不用后来价格补写。上涨、下跌和无结果均保留；统计是事件–CA 观察，不是独立交易数、净收益或因果证明。

只复用现有行情 / 报价与已接入原文，不额外开启抓取、图片下载、收费模型调用或定时 AI 唤醒。Jev 试运行原有期限和预算不变。

## 持久化与运行

由现有模拟引擎每 15 秒整理一次，在同一账本锁和原子写入中保存 `narrativeAcademyMemory`。最多保留 7 天、400 个事件、每事件 12 个 CA；候选超限数显示在报告中，不能冒充全市场覆盖。重启保留首次观察和已完成窗口；模块记忆异常时保留原数据并仅暂停该模块。

本地页面“大脑 → 叙事关联”显示分类计数、前瞻观察数量和能力缺口；动作记录保留原文时间和收录时间。TG / FOMO 监控和百笔本地复盘保持原配置，实盘签名 / 广播权限不变。

研究学习与交易执行分离，依据 `news-trading-logic` 的事件→机制→标的→确认链，以及 `web3-security-trading` 对未知证据的处理要求。不能把已监控、故事好听或源账号有名等同于可以安全买入。
