## 3. 已保存为研究参考的五条原则（未改交易规则）
1. **独立资金去重**：疑似同一协同组单独标记；不把多个组内钱包直接当多个独立确认，保持“证据充分/仅疑似”分层。
2. **跨钱包看库存**：转币不是外部买入。结合 sender/recipient、直接交易回执和后续卖出，防止误报新增资金。
3. **同时保留失败样本**：按链 + CA + 钱包 + 交易哈希归档，不能只取盈利排名或挑出成功的币。
4. **研究可复制性**：短周期、高频套利、路由/撮合优势不一定能在我们看到信号后重现；本轮没有做带延迟、滑点、失败交易成本的跟单回测。
5. **不推测动机**：创建者、手续费受益者、套利钱包、大户分开；叙事需要原文事件和 CA 关联证据补全。

## 4. 复核与数据缺口
- 使用现有 parseWalletActivity / mergeLearningActivity 核验钱包与链绑定、时间、金额一致性并去重；10 份画像均返回正确钱包。
- 通过已有 FIFO 行为分析作离线参考，不把 grossReturn 当扣费净收益。
- 特别补入上一轮独立链上核实的 SAM D→E 转账，将该币在 D/E 的普通 FIFO 归因中隔离：本次已取活动分页没有该转账，不能把 D 的转出当成还持有，也不能把 E 的超额卖出当成无成本利润。
- 一对一同步匹配验证通过：BSC 40 对/12 CA；SOL 23 对/12 CA。并非一个对手交易被重复配对。
- 四个钱包仍有更老分页，本轮只取两页，没有填造完整 30 天逐笔数据。C 返回无下一页也不等于所有链上转账都已收录。
- 盈利发现来源存在选择偏差；后续应在不以盈利排名筛选的新样本上，前向验证独立买盘、分批退出和组内减仓是否改善模拟结果。
- 本轮没有继续下钻其他未知钱包，没有设置自动买入/黑名单/固定止盈止损，没有模型训练、模型 API 请求或账本变更。

结论：**观察，保留为研究参考，不升级为自动跟单教师。** 目前能学到真实交易行为，但尚不能从这些记录推断叙事理解、同一控制人或可复制的盈利能力。
