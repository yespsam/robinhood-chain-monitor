## 事件 → 目标 → 确认 → 退出

1. 对已审核身份的大 KOL，原采集器会丢弃没有 CA / 发币动作的文案。现在将官方 oEmbed 核实后的原文、数字用户 ID、审核快照、身份观察时间及永久链接写入本机 `fomo-x-call-state.json` 的 `narrativeObservations`，不额外公开发布。每人每轮最多四次核实，超额待下轮，失败进入原重试队列；原始发布时间不刷新。
2. 官方网站 / 官方 X / GitHub 复用现有来源校验，不要求正文先包含 CA。任意第三方网址、自称官方、截图或仅图片推文不能自动成为已核实触发源。
3. 滚动保留最多七天文案，按中英文词语、少量双语别名及 Jaccard 重合度检索。至少三个非通用词、重合度至少 72%；这不是语义大模型，不宣称能识别全部梗。通用 AI / crypto / meme 等词、否定警告、引用/回复、身份冲突或同链接内容冲突不触发。
4. 历史文案必须绑定**明确链 + 完整 CA**，且催化出现前曾观察到该币真实成交量 / 流动性或本实验买入。不能从 ticker、同名币或交易哈希前缀猜 CA。OG 指本地该角度最早有绑定记录的候选，不等于全网最早发行认证；最早记录对应多个币则观察。
5. 新催化最多有效 120 秒。历史最高市值 / 当前市值至少 3 倍，作为研究筛选参考；历史市值来自 GMGN，可能超出七天窗口，**不是未来上限或预期收益**。两项任一缺失时空间未知，不能走这条入场分支。
6. 已离开热榜的历史 CA 也进入补查队列，先查行情和安全字段，再优先连续报价。叙事达标可替代常规聪明钱标签要求，但仍要五分钟两个净买家、$500 净流入，90 秒双地址新买盘 / $300 净流入，三次独立报价跨十秒确认、完整安全数据、成本限制与所有账户保护。
7. 相同催化在整个账户最多买一次，去重随成交记录持久化。不同新催化可以重新评估同币，但仍受同币冷却 30 分钟、每日两次亏损禁入、每小时 6 次 / 日 24 次、日亏损 3% / 累计 10% 停机限制。不用新推文绕过旧买盘消费限制。后续按用户要求取消全账户连亏冷静期，改为复盘；上述其他保护不变。
8. 原 V2 退出规则不变：初始价格止损 6%、120 秒价格未走强退出、主仓最多 5 分钟、强势尾仓最多 20 分钟。独立退出监控优先于叙事查询。

## 解释与持久化

模拟买入证据 `entryEvidence.narrativeRecall` 保存新旧原文摘录、各自链接和时间、重合词与分数、历史 CA、OG 选择依据、历史市值参考、之前本账户买过的次数。该证据不会把 `narrativeFresh` 伪装成“作者这次明确推荐该 CA”。

`narrativeMemory` 与当前模拟账本原子保存，共享唯一写锁；重启继续积累。缺少或冲突证据保持观察；记忆损坏停止叙事模块，仍保留持仓退出能力。页面和 `/api/strategy-state` 的 `narrativeRecall` 显示样本量、匹配与缺口。最多 2000 条文案、1000 个资产；只代表本机已采集样本，**不是全网完整七天**。

`PAPER_NARRATIVE_RECALL_ENABLED=true` 启用 KOL 原文采集，需重载 FOMO 采集进程；默认开启。数据仍受上游限流、缺口及审核名单覆盖影响，不承诺推文发表后毫秒级发现。
