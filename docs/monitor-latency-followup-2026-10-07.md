# BSC 与独立 X 监控：后续修补

日期：2026-10-07（Asia/Shanghai）。范围仅采集、调度与持久化；FOMO 平台继续关闭，GMGN 聪明钱、独立 X、其他 TG 与 BSC 模拟盘保留。未调整入场门槛、金额、账本、历史积压政策或 API 限频。

## 原因与变更

1. **X 冷却账号占用轮询名额**：现场覆盖 43/53，另外 10 个账号有有效期内的准入拒绝记录，未发生时间线成功。原调度仍让这些无实际请求的账号占用每批名额。现在跳过尚未到期的准入拒绝，继续轮转至有资格检查的账号；批大小和并发不变，到期后自动重新检查。拒绝账号仍计入覆盖缺口，不能因此把覆盖改报为完整。
2. **FOMO 取消后的缓存依赖**：旧 GMGN 账号若留有 FomoScan 绑定，在下一次资料刷新时可能因平台停用而被误拒绝。现在不再使用该已取消来源的绑定，保留 GMGN 的独立观察归因、推特游标和其他准入检查，不冒充已验证钱包绑定。现场检查未发现当前 GMGN 名册有此残留，本项是回归用例验证的防护，不算新增现场覆盖。
3. **X 拒绝理由混杂**：把非数字 ID、私密账号、固定身份不匹配、粉丝数不足分开记录，覆盖摘要增加各拒绝账号的原因与重试时间。旧拒绝按原重试时间刷新，不额外强制查询。43/53 本身不能证明网络停摆，也不代表另外 10 个都只因粉丝数不足。
4. **BSC 状态读取竞态**：压缩流程先发布新快照再替换 WAL；旧只读流程可能把旧快照与新 WAL 混用，产生假 revision gap，或在空 WAL 时静默返回旧状态。现在读取前后核对快照文件身份，仅在确认切换时重试（最多三次）。稳定的坏校验、缺失版本仍报错；读取不截断 WAL、不重置游标。
5. **BSC 重复深拷贝**：现场状态约 141,460,641 字节。每次快照压缩曾对已与实时状态分离的持久化基线再作全量深拷贝。现在在同一串行 IO 锁内使用浅根快照；锁覆盖快照写入和 WAL 复位，后续写入不能改变正在保存的基线。保留 fsync、重命名、失败恢复和 30 秒快照周期。只消除冗余拷贝，没有删历史或缩短安全检查；JSON 序列化等开销仍存在。
