# 主模拟盘新仓：叙事与资金行为退出

用户明确选择「直接用于主模拟盘后续新仓」。此版本为 `meme_evidence_exit_v1`，仅虚拟账本；不连接钱包、不签名、不广播。既有持仓、成交、独立对照账户的退出版本不改，不重置本金或百笔复盘进度。

## 实际变更

- 新仓不再执行固定百分比止损、固定倍数分批止盈、峰值百分比回撤或持仓时间退出。原入场 profile 和结构价保留供审计，但实际退出以 `memeExitPolicy` 为准，页面不能将原结构价显示成生效止损价。
- 退出仍有明确条件，不是无条件持有：两根入场后收盘破位并下跌放量、放量长上影后跌破、连续三根失守且没有可验证承接、同源多个地址持续新增卖出，均可退出。成交使用其后的新鲜独立观察价，费用/gas/滑点仍是模型，并非实际路由成交承诺。
- 缩量回踩中，完整同源窗口出现至少两个聪明钱标签地址入场后近期买入、且净流入达到 250 U，可继续观察；已确认的下跌放量或派发破位不会被正面喊单覆盖。此规则是待检验假设，不等于识别出“庄家洗盘”。
- 智能钱净卖确认要求至少两个可核对地址，净卖达到 250 U 或入场可见净买的一半（取较大值）；同源观测至少间隔 30 秒，相同地址卖出金额增加且逐笔最新卖出时间晚于首个观察点才确认。重复时间戳、买单滚出五分钟窗口、晚到的旧卖单、来源切换、缺口及换一组地址不能制造持续卖出证据。不是仅凭聪明钱计数。GMGN 标签、币安聪明钱来源和币安 KOL 来源分开，不把 KOL 直接当高盈利地址。
- 入场保存当时可见的聪明钱净买地址群（最多 200，超过注明截断）；出场核对原买家是否转为净卖。地址无新活动不能推断仍持仓；尚未取得完整钱包持仓变动或共同控制证据。

## 叙事与筹码的边界

沿用经过身份校验、精确链/CA 绑定的原文来源。冻结入场来源 ID；入场后的新原文展示出处、时间与原文，并区分「出现后续原文 / 只有背景文案 / 待复核 / 缺少原文」。来源身份正确不代表内容真实；重复、旧文、未绑定、未来时间和冲突内容不能冒充新催化。

本次没有引入预测叙事未来的模型。文案中的否认/争议词只提示复核，不单独卖出；只有同时出现两根收盘破位和完整来源多地址净卖，才作为联合失效依据。新利好文案不能覆盖已确认资金撤退或放量破位。无出处继续标未知，不按币名编故事。

使用现有行情快照的前十大集中度、开发团队占比和打包买入占比，展示相对于入场的百分点变化，不新增持仓 API。指标缺失、错链/CA、未来或过期不计算变化；集中度变化可能有多种原因，不等于转账/卖出，也不能证明共同控制或庄家意图。

此边界遵循 news-trading-logic 的出处与失效条件要求及 web3-security-trading 的证据约束。社会媒体喊单不应独立成为事实依据，参考 [CFTC 对数字代币拉抬出货的说明](https://www.cftc.gov/LearnAndProtect/AdvisoriesAndArticles/beware_virtual_currency_pump_dump.html)。

## 保留项与审计

- 买入资格、固定 10 U、现金约束、安全/成本/新鲜度校验、Plus 限频及监控不停。原入口的 6% 结构空间约束仍用于筛选，**不再是此退出版本的最大损失或触发线**。这轮修改的是退出，不是扩大入口权限。
- `account.memeExitActivation` 保存启用时间与成交基线；新仓/入场证据冻结实际退出策略。卖出记录包含原文摘要、资金/结构/筹码证据和实际版本。复盘按有效版本分组，旧成绩不混作新版成绩。
- 两个原退出实验继续原版本，不切换它们的存续仓位或成交历史；它们不是新主盘的逐笔配对。百笔本地复盘保持仅主盘新买卖计数，AI 十分钟任务继续暂停。
- 无新鲜报价不伪造成交；真实零价格只按既有规则核销。无固定退出百分比可能令亏损扩大或在数据缺失时延迟退出，没有最大亏损保证，未验证盈利。

## 验证

定向测试覆盖：主盘新仓版本/旧仓不改/对照不变；下跌与数倍上涨不触发固定退出；持仓跨日不因时间卖出；结构失效实际卖出与费用记账；前向复盘版本；新鲜/错链/未来/不连续数据；缩量承接、旧买盘排除与放量失效；重复或晚到卖盘、地址切换、跨来源/不完整覆盖；币安无 tags 的来源映射；叙事身份绑定、争议词单独不退出；筹码观察非操盘结论；页面转义与实际退出标签；运行时重启、暂停新仓后的退出检查及百笔进度保持。

运行开关 `PAPER_MEME_EXIT_MODE=0` 仅使后续新仓不再采用本版，已有本版持仓仍按冻结版本管理；不能用开关给旧仓套新价格止损。默认构造器为关闭，生产入口根据本次明确授权启用。
