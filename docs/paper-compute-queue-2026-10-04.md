1. 新增有界纯文字缓存：正文规范化 512 项（每项最多 8,000 字符）、币名匹配规则 512 项（每项最多 256 字符）、中文叙事分词 2,048 项（每项最多 4,000 字符）。按完整文本缓存而不是链接/币名对象身份；超长或非字符串输入仍按原算法计算，不截断。分词返回副本，内部正则不向外暴露。采用 LRU 淘汰，不无限积累。
2. 不缓存来源认证、事件时效、CA 绑定、同名冲突、行情、交易决定。每轮继续验证这些字段，修改过的原文不会命中旧内容。
3. 原生 GMGN 只读请求每次仍执行一次 `config --check`，但在取得共享业务名额之前完成。核对已安装 CLI 的 `dist/commands/config.js:101`，该分支只检查本地配置，不请求行情。检查任务受原有本地就绪数量限制；真实业务仍经过共享账户排队、原并发/间隔、退出优先级、429 共同冷却。实际发起前再次检查冷却；报价时间及最新闭合 K 线窗口仍绑定实际业务发起时间。未提高 API 限额、未修改共享锁或手工清队列。
4. 增加新闻匹配、叙事回忆阶段耗时；仅允许聚合计时进入公开投影。没有在本轮部署远程静态页面或重启公开发布器。

Web3 安全技能限制了优化范围：真实报价、税率、可卖性和未知证据处理保持不变。GMGN 行情技能要求每请求配置校验与遵守共同冷却；本轮未跳过这些步骤。只读取安装程序源代码，未读取或输出秘密配置、密钥、私钥或绑定实盘钱包，也没有手动新增 GMGN 业务查询或模型调用。
