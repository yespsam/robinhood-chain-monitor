# Jev 有界语义研究试运行

用户在首次三次真实旁路测试后确认“开始吧”。本次接入现有估算费用独立模拟盘的研究调度，不接管实盘或更改入场/退出规则。

## 固定边界

- 手动单次启用，30 次调用预算或 1 小时，先到停止新增请求；最短请求间隔 10 秒，单请求在途，接口超时 2.5 秒。
- 不新增 Codex 定时唤醒，不自动续期，不重试失败请求。普通行情、模拟盘、TG 不依赖 Jev 成功。
- 先落盘预留额度，再请求固定官方 API；重启后保留预算和去重记录。未完成记录、配置损坏、锁冲突或接口失败只停止这个研究模块。
- 去重键含问题版本、链、CA、去参数原文链接、实际摘录；价格、引用年龄、扫描时间变化不会重复计费。
- 只使用带原始时间且一小时内的来源；明确风险或税率超过 6% 不发模型请求。研究不要求报价已新鲜，但真实模拟成交仍要求原有报价和入场校验。
- 只传现有 adapter 的公开字段白名单；不传余额、成交账本、钱包私钥、API 密钥或原始完整候选对象。私有状态文件权限 0600。

## 调度影响

Jev 判断文案关联、事件表述、需求路径，不核实新闻真实性，不预测价格。

- 只有本地已有 CA 对应证据，且三个分类置信度均达到实验阈值 0.8，才能给予最多 20 分的叙事研究加分。
- 高置信度“无关/否认”最多减少 20 分的新闻研究加分；不扣独立量价/资金得分，不封锁其他交易路线。
- 同名、低置信度或未知结果不提升 CA 身份，也不批准买入。
- 保留各链研究轮转、冷门发现名额和持仓退出优先级。结果最多使用 15 分钟，且不超过原文时效与试运行期限。
- 模型响应永不写入交易许可、成交、余额或持仓退出规则。

本地 `/api/strategy-state` 的 `jevResearch` 显示预算占用、成功次数、token 用量、最近真实分类及耗时。`#brainDesk` 的“叙事”模块与动作记录显示中文摘要，明确这不是私有思维流或买入批准。公网 UI 暂未部署此新增展示。

## 操作与验证

显式创建：`node scripts/start-jev-research-pilot.js`。已有文件时拒绝覆盖或自动续期；创建后通过现有 dashboard 服务平滑重载读取。

只重载模拟盘 dashboard，不重启 TG/FOMO。原主盘账本、活动会话选择和已保存密钥均保持不变。

离线测试覆盖：请求去重、持久预算、单请求并发、期限、源数据/CA 绑定、密钥隔离、真实 adapter 响应往返、失败无重试、断点恢复、调度不改变交易资格、中文展示。这里的 fixture 测试不是实盘成交验证。

叙事分析技能用于将原文分类与交易机制分开；链上安全技能用于保持 CA、税率、报价及执行权限的独立校验。试运行不构成盈利保证或模型训练。
