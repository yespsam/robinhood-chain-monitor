# ETH 研究与成本链路修复

## 已核实的故障

ZC / zipcoin（ETH `0x2ca7b61b23b15e75ac7ab60dd6f627895d64a46e`）已出现在候选池，但主盘热点研究派发为零。旧模型把 ETH 单边 Gas 固定为 2 美元；当前单笔预算 8.77U 对应 48.64% 模型往返成本。研究调度也复用成本上限，导致尚未研究就排除该链。

另一个独立问题是交易 `0xdb3ebfc6f0f59dd5bb72cddbbf69bd561253223240c3e9fb58f8ef67ce0efafd`：同一钱包同一时间卖出同一个币，但 API 返回两路成交。链上成功回执中，该钱包实际转出合计 555930.4983798644 个 ZC，与两路数量总和一致。原解析器把它当作重复记录冲突并隔离整个 CA。

## 变更与边界

- 主模拟盘热点研究不再复用成本买入门槛；仍每链一个热点席位，持仓退出优先，不增加并发或绕过 API 限流。交易成本上限不变。
- 每 30 秒最多一次只读 ETH RPC 批量采集，校验主网 chainId、最新区块、Gas 单价、Chainlink ETH/USD feed 身份和更新时间。90 秒后 Gas 证据失效，USD 价格超过一小时也失效。
- 新仓 Gas 为链上单价 × 250000 Gas 模型用量 × 1.25 缓冲 × ETH/USD。用量、滑点、平台费仍是模型，不是特定代币路由报价，不保证实际手续费。真实成本过高仍不入场；失败或陈旧证据不能冒充有效低费率。
- 分析与串行模拟成交均校验同一份费用证据；旧仓冻结的成本与历史账本不改写，不补款或补单。
- 仅对 ETH 同交易/钱包/CA/方向/时间的冲突，最多每轮复核两笔链上回执。要求成功回执、发起钱包、区块哈希和时间匹配、钱包单向代币净移动与去重后拆单数量一致。失败、双向转账、缺失或数量不符仍隔离。USD 数值仍为 GMGN 报告，不声称链上有美元价格。
- 拆单先去重再合计，保留回执依据；后续只返回部分成交时不覆盖已核实总量。买入美元修订取低、卖出取高。旧隔离自然到期并重建覆盖窗口，不手动删除隔离或伪称历史完整。
- 完整推特原文覆盖缺口未由这次修复解决；GMGN 平台喊单不能冒充完整 ETH 推特监控。
