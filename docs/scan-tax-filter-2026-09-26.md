# 扫描税率上限

规则版本：`scan_tax_cap_6pct_v1`。

- 所有链的新开仓统一检查：买入税或卖出税任一 **大于 6%**，标记“不买”并记录实际税率。
- 恰好 6% 不被此上限过滤；不是买卖税率相加，也不等于通过其他成本、行情或买入条件。
- 上游使用小数比例，例如 `0.06` = 6%。缺失、非法值、百分比字符串或越界数值不当成零税，不猜单位。
- 扫描先排除已知高税 CA 的主题选币、候选详情、入场报价和 K 线研究；普通策略、监控消息快线、Alpha 上新及模拟成交入口再次检查。
- 原始消息、TG 监控和历史学习不关闭；过滤原因仍保留在决策记录中。
- 已有持仓不因新上限失去报价、退出管理或旧账本兼容性。此改动不启用实盘、签名或资金调拨。
- `taxFilter` 状态为当前去重候选快照；`blocked` 最多展示 60 条，完整计数为 `blockedCount`，并非累计过滤次数。

验证覆盖边界值、双向税率、异常数据、多源合并、普通/Alpha/监控路径、入账复核及旧仓退出。
