# 起量 / 高市值叙事自动学习

2026-09-23，扩展 yesp atm 现有模拟盘。只新增观察学习，不重置本金、不修改买点风控、不签名或广播。

## 自动采样

- 复用 GMGN 每条已启用链的 `trending interval=1m` 原始快照；不从合并候选或 1h / 24h / 内盘不明周期成交量冒充 1m。
- 初始研究条件：市值至少 $1,000,000，流动性至少 $20,000，一分钟成交额至少 $10,000，且为此前基线的至少三倍。这是采样阈值，不是选币建议或买入条件。
- 基线为此前十五分钟已采到的 1m 滚动成交额快照中位数，至少三个不同分钟、跨度至少两分钟、最近基线距当前不超过三分钟。不是完整连续 K 线；样本不足或基线为零时不猜测起量。
- 同分钟 / 相同缓存快照不重复计数。同币同一波放量只记一次；要先观察到回落至 1.5 倍以下，并相隔至少三十分钟，才记录下一波。
- 保存精确链、CA、源观察时间、市值、流动性、成交额、基线、放量倍数及当时已知异常标签。观察到的危险代币可作为反面研究样本，但不因此允许交易。

## 自动找文案

1. 优先匹配已有经过来源核验、明确绑定该链与 CA 的文案。
2. GMGN 项目字段含有完整 X / Twitter **具体推文永久链接**时，自动从固定的官方 oEmbed 端点取原文，验证作者页面和具体 status 链接；不访问任意网站、不跟随重定向、不登录或携带密钥。响应上限 128 KiB、超时八秒。
3. 具体推文的发布时间从 X snowflake ID 推导。只关联起量前、近七天内的帖子；后来发布的文案不能解释先前起量。后来才找到的旧帖单独记下关联时间，不回写成当时已知。
4. oEmbed 原文真实性、GMGN 项目链接关联、作者认可该 CA 是三个不同问题。只有前两项的样本标为 `provider_permalink`，与 `verified_ca` 分组；不进入旧叙事 OG 自动入场证据。
5. 只有账号主页、项目描述、同名 ticker、未核实页面或图片时，不补写推文或叙事。市场事件继续保存，显示待核实。项目自述仅存为未经核实材料。
6. 失败最多三次尝试，间隔五分钟 / 三十分钟；结果随账本持久化。原监控有来源缺口，不能保证每条链、每个币或每条推文都覆盖。

## 结果与学习

- 起量后复查 5 分钟、1 小时和 24 小时；容差分别为 2 / 5 / 15 分钟。只取窗口内第一条新鲜、同链同 CA 的观察价。缺失保留为缺失，不当作零收益、亏损或事后补齐的回测。
- 复用已有行情和报价。离开热榜但复查已到期的币，可用低优先级只读查询复查；学习价格查询与原文查询共用每分钟最多一次新增请求的预算，价格复查优先。持仓缺少退出报价时不新增学习查询；不污染交易报价缓存。
- 同时记录观察到的峰值、低点和峰值回撤。这些都是采样得到的上下界，不是真实最高 / 最低价；后续价格变化未计成本，不等于可实现利润。
- 按文案非通用词重合归并相近角度，分别统计上涨、下跌、持平和“曾涨至少 20% 后，24 小时回到起点或以下”。保留失败样本；不把没有叙事的起量删除。
- 已核实组至少十个 24h 完整样本、五个不同代币、三个不同日期才标记可供后续样本外研究，仍不证明叙事因果或盈利。链接关联组一直注明 CA 关系未确认。
- 当前是可追溯案例库和统计学习，不是 LLM 权重训练；不会自动放宽开仓、去掉止损或按相关性追涨。没有人工伪造成交或人为填充样本。

## 存储、覆盖和恢复

`narrativeLearningMemory` 与当前模拟账本共用唯一写锁和原子保存；最多 600 个基线、500 个待完成 24 小时观察的事件和 1,500 个已结案事件，总上限 2,000，最长保留 30 天，重启继续。容量上限可能使实际历史短于 30 天，不代表完整市场覆盖。学习记忆损坏时保留原数据并单独停用学习，退出管理和账户不重建。暂停新开仓仍继续观察学习。
