# yesp atm 决策大脑

入口：`http://127.0.0.1:4173/#brainDesk`。这是已有运行数据的只读视图，不是模型私有思维流，也不是新增自主下单权限。

## 页面

- 六个可点击模块：消息感知、叙事关联、资金研究、量价研究、决策检查、执行复盘。
- 当前任务由后台资料请求、报价请求、K 线任务推导；区分已派发、等待回包、成功、缺失和过期。没有记录时不生成动作。
- 关注对象默认跟随研究候选，也可锁定链与精确 CA；点击完整依据打开并选中逐币判断台的同一对象。候选不是已成交。
- 操作记录按研究、成交、复盘筛选。成交来自主账本，不混入对照或诊断成交；研究日志来自后台保留快照和本页观察，不声称完整历史。最多保留 30 条成交、49 条研究、1 条最近复盘；每个筛选展示最近 8 条。
- 旧研究列表收进研究档案；已结束的独立诊断也归档，仍活跃的诊断持仓继续在主区显示。原有深链接仍可展开所在档案。

## 边界

没有新增轮询器或上游请求，复用已有单飞 `/api/strategy-state`；页面目标每秒同步不等于上游每个代币每秒更新。断线、未来时间或超过 15 秒的本地快照取消活动状态并标记过期，保留最后记录。动画支持减少动态效果设置。

本次未修改模拟盘入场、退出、资金、百笔复盘条件，未重启监控和后台。没有实盘、签名或广播操作。
