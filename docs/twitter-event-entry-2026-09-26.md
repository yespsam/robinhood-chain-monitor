# 推特事件优先的模拟盘入口（2026-09-26）

## 查到的断点

- 独立人物 / 平台推特原文原先只进入 `narrativeResearchIndex`，没有进入 `buildPaperNewsWire`，因此不能触发主盘新闻候选。
- 新帖子即使与同一人物的历史题材相同，也没有复用历史学习中已核验的项目原帖。比如 e/acc 当前项目资料引用 Beff 的旧帖，而当天后续帖使用不同 status ID。
- 对照账户的待更新持仓 K 线在主盘入场候选之前，能持续挤占研究槽。
- `chartReadyCandidates` 实际统计“可以进入报价阶段的候选”，不是所有可用 K 线的数量；不能据此声称上游所有 K 线都不可用。

## 本次变更

1. 独立原文通过账号固定 ID、官方 oEmbed 原文、原发布时间和回复 / 引用状态验证后，进入主盘消息线。
2. 事件文案先提取明确概念，再匹配候选名字、符号、上游字符串标签。显式别名支持 e/acc / effective accelerationism，以及中秋 / 月饼 / mooncake；其他名称保留词边界匹配，中文可从两个字开始。宽泛 AI 等标签不构成催化。
3. 区分原文直接 CA、项目资料引用该帖、同作者同概念的历史原帖关联、只有名字 / 标签相同。历史来源可复用七天内已核验学习文案，但不使用事后价格成绩筛选，不把历史采集时间改成发布时刻。
4. 多个 CA 同等关联时不按流动性猜正统币。原文否认 / 卖出、重复文案、冲突来源、失去身份绑定、过期行情不产生该入口信号。新的否认也撤销同作者旧的正向信号。
5. 唯一关联通过后进入现有恢复期主盘检查，仍须实际买盘、独立报价、费用、税率、余额、退出可观测性。此入口总是要求事件后两次走强报价，不靠一条名字匹配强制填单。
6. 新增看板“推特事件 → 叙事 → CA”：展示原文、叙事主张、匹配名字 / 标签、历史出处、候选 CA 和当前未买原因。
7. `main_entry_fairness_v12`：主盘退出仍优先；对照盘在非主盘槽中每四次保留一次或使用空闲容量，不能阻塞主盘候选的有限专注窗口。未提升 Plus 配额，未停 TG / FOMO。

## 明确未完成的覆盖

- 这是规则辅助证据映射，不是通用语义模型，也不是已学会所有 meme 叙事。仅搜索当前扫描及本地已知 CA，不代表全链所有代币。
- 独立源目前仅固定 Beff / UsePaid；原有已核验 KOL 监控继续进入同一消息线，GMGN 平台喊单仍不能替代完整推文。
